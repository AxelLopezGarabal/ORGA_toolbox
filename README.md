# ORGA_toolbox
Conjunto de herramientas para la resolución/verificación de ejercicios de la materia Organización de computadoras.
## Link a la pagina
https://axellopezgarabal.github.io/ORGA_toolbox/index.html

## Detalle con respecto a la materia
Las herramientas contenidas tienen como propósito el facilitar la comprencion de las resoluciones de los ejercicios de los siguientes temas:
- Cache
- Pila
- Lógica digital
- Buses
- Sistemas de numeracion
